✍️ Utiliser une visualisation dans un cours Markdown

Dans n'importe quel module ou antisèche (matieres/**/md/*.md), ajoute un bloc :

::: viz gradient Descente de gradient sur une fonction non convexe
fonction: nonconvexe
lr: 0.02
:::

Widgets : relation, matrice, gradient, regression, normale, bayes, pascal, graphe, entropie, bloom, kmeans, seuil, activation, convolution, ownership, jointure, mapreduce, hachage, attention. Options détaillées : .github/instructions/creer-un-cours.instructions.md.
