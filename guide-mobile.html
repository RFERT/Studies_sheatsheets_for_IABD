Réviser sur ton téléphone 📱

Trois façons d'ouvrir ce site sur ton Samsung — de la plus simple à la plus complète. Le site est 100 % hors-ligne (aucune donnée envoyée).

1. Le serveur local ★ Recommandé

Ton PC sert les fichiers, ton téléphone les lit via le Wi-Fi. Toutes les fonctions marchent (progression, recherche, thème) et aucune connexion Internet n'est nécessaire.

  1. PC et téléphone sur le même Wi-Fi.
  2. Sur le PC, ouvre un terminal dans le dossier du site et lance : python -m http.server 8000
  3. Trouve l'adresse IP locale du PC : tape ipconfig (Windows) et repère « Adresse IPv4 », par ex. 192.168.1.23.
  4. Sur le téléphone, ouvre le navigateur et va sur : http://192.168.1.23:8000 (remplace par ton IP). 🎉

Astuce : si ça ne charge pas, autorise Python dans le pare-feu Windows, ou vérifie que le réseau Wi-Fi est en profil « Privé ».

2. Mettre en ligne (GitHub Pages) ★ Pratique partout

Comme le dossier est déjà un dépôt Git, tu peux le publier gratuitement et y accéder depuis n'importe où, sans PC allumé — idéal dans les transports.

  1. Pousse le dépôt sur GitHub (repo public ou privé).
  2. Sur GitHub : Settings → Pages.
  3. « Build and deployment » → Source : Deploy from a branch, branche main, dossier /root, puis Save.
  4. Après ~1 min, l'URL https://<ton-pseudo>.github.io/<repo>/ ouvre le portail sur le téléphone.

👉 Pas à l'aise avec Git/GitHub ? Suis le guide complet GitHub Pages (pas à pas, pour débutant). Bonus : ajoute la page à l'écran d'accueil (voir plus bas) pour une icône comme une vraie app.

3. Copier les fichiers directement Le plus simple

Sans PC ni réseau : on transfère le dossier sur le téléphone et on ouvre la page.

  1. Copie le dossier complet Studies_sheatsheets_for_IABD sur le téléphone (câble USB, Google Drive, ou une clé USB-C).
  2. Avec un gestionnaire de fichiers, ouvre index.html avec un navigateur (Chrome, ou une app type « HTML Viewer »).

Limite : certains navigateurs mobiles bloquent les fichiers locaux (file://), ce qui peut désactiver la recherche ou la sauvegarde de progression. Si tu rencontres ça, préfère la méthode 1 ou 2.

📌 Ajouter à l'écran d'accueil (icône « app »)

Dans Chrome mobile : menu ⋮ → Ajouter à l'écran d'accueil. Tu obtiens une icône 🎓 qui ouvre le portail en plein écran, comme une application.

💡 Quelle méthode choisir ?

À la maison, PC allumé → méthode 1 (serveur local). En déplacement → méthode 2 (GitHub Pages). Dépannage rapide sans réseau → méthode 3.
