Module 2 — Anatomie du corps humain

L'anatomie décrit la structure du corps : où sont les organes, comment ils sont organisés et quel vocabulaire les situe. C'est la carte indispensable pour comprendre la physiologie, les pathologies et les voies d'administration.

SCIENCES
🎯 Objectifs Connaître les niveaux d'organisation et les 4 tissus ; utiliser les plans et termes de position ; situer les grands systèmes (locomoteur, cardiovasculaire, respiratoire, digestif, nerveux).

1. Niveaux d'organisation & tissus

Du plus petit au plus grand atome → molécule → cellule → tissu → organe → système (appareil) → organisme.
Les 4 types de tissus
  • Épithélial : revêtement & glandes (peau, muqueuses).
  • Conjonctif : soutien (os, cartilage, sang, graisse).
  • Musculaire : contraction (squelettique, cardiaque, lisse).
  • Nerveux : transmission de l'information (neurones).

2. Position & repères anatomiques

Position anatomique de référence Sujet debout, regard horizontal, bras le long du corps, paumes vers l'avant. Toute description se fait par rapport à cette position.
Plans & directions
  • Plan sagittal : sépare gauche/droite · frontal (coronal) : avant/arrière · transversal : haut/bas.
  • Supérieur/inférieur, antérieur/postérieur, médial/latéral (vers/loin de l'axe), proximal/distal (membres), superficiel/profond.
💡 Au comptoir Ce vocabulaire sert à comprendre une ordonnance ou une notice : « application sur la face antérieure de l'avant-bras », « voie sous-cutanée », « partie distale du membre ».

3. Système locomoteur

Os, articulations, muscles Le squelette adulte compte environ 206 os. Il protège (crâne, cage thoracique), soutient et permet le mouvement grâce aux articulations et aux muscles squelettiques.
Classification des os Longs (fémur), courts (carpe), plats (sternum, os du crâne), irréguliers (vertèbres). Les os longs contiennent la moelle osseuse (production des cellules sanguines).

4. Système cardiovasculaire

Le cœur : une double pompe 4 cavités : 2 oreillettes (en haut, reçoivent le sang) et 2 ventricules (en bas, éjectent le sang). Le cœur droit envoie le sang aux poumons ; le cœur gauche l'envoie dans tout le corps.
Les vaisseaux
  • Artères : partent du cœur (sang sous pression, paroi épaisse).
  • Veines : reviennent au cœur (valvules anti-reflux).
  • Capillaires : échanges avec les tissus (O₂, nutriments, déchets).
⚠️ Idée reçue « Artère = sang oxygéné » est faux en général : l'artère pulmonaire transporte du sang pauvre en O₂ vers les poumons. La règle vraie est : artère = part du cœur.

5. Système respiratoire

Le trajet de l'air nez/bouche → pharynx → larynx → trachée → bronches → bronchioles → alvéoles pulmonaires, où se font les échanges gazeux (O₂ entrant, CO₂ sortant).
💡 Lien galénique Cette anatomie explique la voie inhalée (asthme, BPCO) : l'aérosol doit atteindre les bronchioles. La taille des particules conditionne où le médicament se dépose.

6. Systèmes digestif & nerveux

Tube digestif bouche → œsophage → estomac → intestin grêle (absorption des nutriments) → côlon (eau, résidus) → rectum/anus. Glandes annexes : foie, vésicule biliaire, pancréas.
Système nerveux SNC = encéphale + moelle épinière (centre de commande). SNP = nerfs (transmission vers/depuis les organes). Le système nerveux autonome règle les fonctions involontaires (cœur, digestion).

7. Exercices de synthèse

Exercice 1 — Vocabulaire de position

Classe ces structures du plus médial au plus latéral sur la main en position anatomique : pouce, auriculaire, majeur.

Voir la solution

En position anatomique (paume vers l'avant), le plus médial (proche de l'axe) est l'auriculaire, puis le majeur, puis le pouce (le plus latéral). C'est l'inverse de l'intuition « main posée sur la table ».

Exercice 2 — Trajet du sang (⭐)

Décris le trajet d'une goutte de sang depuis le ventricule droit jusqu'au ventricule gauche.

Voir la solution

Ventricule droit → artère pulmonaire → poumons (oxygénation) → veines pulmonaires → oreillette gauche → ventricule gauche. C'est la petite circulation (pulmonaire).

Exercice 3 — Relier structure & fonction (⭐)

Pourquoi une pommade appliquée sur la peau agit-elle surtout localement, alors qu'un patch peut agir sur tout le corps ?

Voir la solution

La peau (tissu épithélial) est une barrière. Une pommade reste en surface (effet local). Un patch transdermique est conçu pour franchir l'épiderme et atteindre les capillaires du derme, passant alors dans la circulation générale (effet systémique).
