## ⚛️ L'atome & les ions

- **Noyau** = protons (+) + neutrons (0) ; **électrons** (–) autour. Atome neutre : nb d'e⁻ = nb de protons.
- **Z** (numéro atomique) = nombre de ==protons== → c'est lui qui définit l'élément.
- **A** (nombre de masse) = protons + neutrons. **Isotopes** : même Z, A différent (¹²C et ¹⁴C).
- **Cation** = ion + (perte d'e⁻ : Na⁺, K⁺, Ca²⁺) ; **anion** = ion – (gain d'e⁻ : Cl⁻).

:::mnemo
Le « t » de **ca**tion ressemble à un **+** : il a **perdu** des électrons.
:::

Les [[électrolytes|ions minéraux (Na⁺, K⁺, Ca²⁺, Cl⁻) indispensables au fonctionnement des cellules]] : sérum physiologique = NaCl 0,9 %.

→ Cours : [L'atome & le tableau périodique](modules/chimie.html#atome)

## 🔗 Les 3 liaisons

| Liaison | Principe | Exemple |
|---|---|---|
| **Covalente** | partage d'électrons | H₂O, molécules organiques |
| **Ionique** | attraction ions + / – | NaCl (se dissocie dans l'eau) |
| **Hydrogène** | liaison faible H–(O,N) | cohésion de l'eau, protéines, ADN |

- L'eau est une molécule [[polaire|molécule avec un pôle δ+ et un pôle δ– : elle dissout les ions et les molécules polaires]] → **solvatation** des ions.
- PA **polaire** = hydrosoluble ; PA **apolaire** = ==lipophile== (préfère les graisses).

→ Cours : [Liaisons chimiques](modules/chimie.html#liaisons)

## 🧮 Mole, concentrations, dilutions

| Grandeur | Formule | Unité |
|---|---|---|
| Masse molaire M | somme des masses atomiques | g/mol |
| Concentration molaire C | C = n / V | mol/L |
| Concentration massique Cₘ | Cₘ = m / V | g/L |
| Lien | Cₘ = C × M | |
| Dilution | C₁V₁ = C₂V₂ | soluté conservé |

:::calc Exemple — NaCl
M(NaCl) = 23 + 35,5 = **58,5 g/mol**.
Sérum physiologique 0,9 % = **9 g/L** → pour 500 mL : 9 × 0,5 = **4,5 g**.
:::

:::calc Exemple — dilution
Obtenir 250 mL à 0,1 mol/L depuis une mère à 1 mol/L :
V₁ = (0,1 × 250) / 1 = **25 mL** de mère, complétés à 250 mL.
:::

→ Cours : [Mole, concentrations & dilutions](modules/chimie.html#solutions)

## ⚠️ Pièges de calcul

:::warn Unités
- Toujours convertir les volumes en **litres** (mL ÷ 1000) avant de calculer.
- « 0,9 % (m/V) » = **0,9 g pour 100 mL** = 9 g pour 1000 mL.
- On ne « rajoute pas V₂ de solvant » : on prélève V₁ puis on **complète à V₂** (QSP).
:::

:::retenir
Facteur de dilution = C₁ / C₂ = V₂ / V₁. Ex. eau oxygénée 30 % → 3 % : facteur **10** ; pour 200 mL, on prélève 20 mL.
:::

## 🧪 Acides, bases, pH

- **pH = −log[H₃O⁺]** ; échelle 0 à 14 (à 25 °C).
- pH < 7 : ==acide== · pH = 7 : neutre · pH > 7 : ==basique==.
- **Acide** = libère des H⁺ ; **base** = capte des H⁺. Fort = totalement dissocié ; faible = partiellement.
- Un [[tampon|solution qui résiste aux variations de pH quand on ajoute un acide ou une base]] stabilise le pH (sang : système bicarbonate).

:::seuil Valeurs à retenir
| Milieu | pH |
|---|---|
| Suc gastrique | ≈ 1,5 – 2 |
| Sang | ≈ **7,40** |
| Sécrétions pancréatiques | ≈ 8 |
:::

- Sang **< 7,35** = acidose ; **> 7,45** = alcalose.

## 🧬 Fonctions organiques

Carbone **tétravalent** (4 liaisons) : base de presque tous les médicaments.

| Fonction | Groupe | Exemple |
|---|---|---|
| Alcool | –OH | éthanol |
| Acide carboxylique | –COOH | aspirine |
| Amine | –NH₂ | PA basiques |
| Ester | –COO– | liaison de l'aspirine |
| Amide | –CO–NH– | paracétamol |
| Cétone | >C=O | corps cétoniques |

:::why Pourquoi ça compte
La fonction détermine la **solubilité** (–COOH, –OH → hydrosoluble), l'**acido-basicité** et la **réactivité**. L'aspirine est un ester : l'humidité l'**hydrolyse** → conservation au sec.
:::

→ Cours : [Chimie organique & fonctions](modules/chimie.html#orga)

## 🎯 Pièges d'examen & trous à réviser

:::warn Confusions classiques
- **Z** (protons) ≠ **A** (protons + neutrons).
- Changer les neutrons → **isotope** ; changer les électrons → **ion** ; l'élément reste le même.
- Liaison des molécules organiques = **covalente** (pas ionique).
:::

- La liaison entre ions de charges opposées est la liaison ==ionique==.
- Formule de dilution : ==C₁V₁ = C₂V₂==.
- Un tampon résiste aux variations de ==pH==.
- Le paracétamol possède une fonction ==amide== et un ==phénol==.
