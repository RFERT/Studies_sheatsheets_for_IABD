## 🧱 Niveaux d'organisation & 4 tissus

**atome → molécule → cellule → tissu → organe → système (appareil) → organisme**

| Tissu | Rôle | Exemples |
|---|---|---|
| **Épithélial** | revêtement, glandes | peau, muqueuses |
| **Conjonctif** | soutien | os, cartilage, **sang**, graisse |
| **Musculaire** | contraction | squelettique, cardiaque, lisse |
| **Nerveux** | transmission de l'information | neurones |

:::mnemo
**ÉCMN** : Épithélial – Conjonctif – Musculaire – Nerveux.
:::

- Le sang est un tissu ==conjonctif== : cellules (globules) dans une matrice liquide, le [[plasma|partie liquide du sang dans laquelle baignent les globules]].

→ Cours : [Niveaux d'organisation & tissus](modules/anatomie.html#niveaux)

## 🧭 Position & repères

**Position anatomique de référence** : debout, regard horizontal, bras le long du corps, paumes vers l'**avant**.

| Plan | Sépare |
|---|---|
| **Sagittal** | droite / gauche |
| **Frontal** (coronal) | avant / arrière |
| **Transversal** | haut / bas |

| Termes | Sens |
|---|---|
| Supérieur / inférieur | vers la tête / vers les pieds |
| Antérieur / postérieur | face avant / face arrière |
| Médial / latéral | vers / loin de l'axe du corps |
| **Proximal / distal** | près / loin de la racine du membre |
| Superficiel / profond | près / loin de la surface |

:::example Exemple
Le poignet est plus éloigné de l'épaule que le coude : il est ==distal== par rapport au coude.
:::

:::tip Au comptoir
Ce vocabulaire sert à lire une ordonnance ou une notice : « face antérieure de l'avant-bras », « voie sous-cutanée ».
:::

→ Cours : [Position & repères anatomiques](modules/anatomie.html#reperes)

## 🦴 Système locomoteur

- Squelette adulte ≈ ==206 os== : protège (crâne, cage thoracique), soutient, permet le mouvement (articulations + muscles squelettiques).
- Classification : **longs** (fémur) · **courts** (carpe) · **plats** (sternum, crâne) · **irréguliers** (vertèbres).
- La [[moelle osseuse rouge|tissu des os plats et des extrémités des os longs où se fabriquent les cellules du sang (hématopoïèse)]] produit les globules.

→ Cours : [Système locomoteur](modules/anatomie.html#loco)

## ❤️ Système cardiovasculaire

- Cœur = **double pompe**, **4 cavités** : 2 **oreillettes** (reçoivent) + 2 **ventricules** (éjectent).
- **Cœur droit** → sang vers les poumons (petite circulation) ; **cœur gauche** → sang vers tout le corps (grande circulation).

| Vaisseau | Sens / rôle | Particularité |
|---|---|---|
| **Artères** | partent du cœur | paroi épaisse, sang sous pression |
| **Veines** | reviennent au cœur | valvules anti-reflux |
| **Capillaires** | échanges avec les tissus | O₂, nutriments, déchets |

:::calc Trajet du sang (petite circulation)
Ventricule droit → artère pulmonaire → poumons → veines pulmonaires → oreillette gauche → ventricule gauche.
:::

:::warn Idée reçue
« Artère = sang oxygéné » est **faux** en général : l'artère pulmonaire porte du sang pauvre en O₂. Règle vraie : **artère = part du cœur**.
:::

→ Cours : [Système cardiovasculaire](modules/anatomie.html#cardio)

## 🫁 Système respiratoire

**nez/bouche → pharynx → larynx → trachée → bronches → bronchioles → alvéoles**

- Les [[alvéoles|petits sacs pulmonaires entourés de capillaires où se font les échanges gazeux]] : O₂ entre, CO₂ sort ; immense surface d'échange.
- Lien galénique : la voie ==inhalée== (asthme, BPCO) doit atteindre les bronchioles ; la taille des particules détermine où le médicament se dépose.

→ Cours : [Système respiratoire](modules/anatomie.html#respi)

## 🍽️ Tube digestif

**bouche → œsophage → estomac → intestin grêle → côlon → rectum/anus**

| Segment | Fonction principale |
|---|---|
| Estomac | digestion (acide) |
| **Intestin grêle** | **absorption** des nutriments (villosités) |
| Côlon | réabsorption d'eau, résidus |

- Glandes annexes : **foie**, vésicule biliaire, **pancréas**.

→ Cours : [Digestif & nerveux](modules/anatomie.html#autres)

## 🧠 Système nerveux

- **SNC** = encéphale + moelle épinière (centre de commande).
- **SNP** = nerfs (transmission vers/depuis les organes).
- Le système nerveux **autonome** règle les fonctions involontaires (cœur, digestion).

→ Cours : [Digestif & nerveux](modules/anatomie.html#autres)

## 🎯 Pièges d'examen & trous à réviser

:::warn À ne pas confondre
- **Oreillettes** = reçoivent ; **ventricules** = éjectent.
- **Médial** ≠ **proximal** (médial : par rapport à l'axe du corps ; proximal : par rapport à la racine du membre).
- Sur la main en position anatomique, le plus **médial** est l'auriculaire, le plus latéral est le pouce.
- Pommade = effet **local** (reste en surface) ; patch transdermique = effet **systémique**.
:::

- Le plan qui sépare la droite et la gauche est le plan ==sagittal==.
- Les échanges gazeux se font dans les ==alvéoles==.
- L'absorption des nutriments a lieu surtout dans l'==intestin grêle==.
- Le SNC comprend l'==encéphale== et la ==moelle épinière==.
