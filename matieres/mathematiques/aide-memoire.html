Lois de De Morgan

\[\neg(P\land Q)\equiv \neg P\lor\neg Q\qquad \neg(P\lor Q)\equiv \neg P\land\neg Q\]

➗ Vecteurs IA📘 Module 2

Norme & produit scalaire

\[\|x\|_2=\sqrt{\textstyle\sum_i x_i^2}\qquad x\cdot y=\sum_i x_i y_i\]

Similarité cosinus

\[\cos(\theta)=\frac{x\cdot y}{\|x\|\,\|y\|}\in[-1,1]\]
UsageCosinus ≈ 1 → vecteurs très similaires (recommandation, recherche sémantique, embeddings).

Distances : \(L_1=\sum|x_i-y_i|\) (Manhattan), \(L_2=\sqrt{\sum(x_i-y_i)^2}\) (euclidienne).

🔲 Matrices IA📘 Module 2

ObjetFormule / sens
Produit\((AB)_{ij}=\sum_k A_{ik}B_{kj}\)
Transposée\((A^\top)_{ij}=A_{ji}\)
Identité\(AI=IA=A\)
Inverse\(AA^{-1}=I\) (si \(\det A\neq 0\))
Déterminant 2×2\(ad-bc\)
Attention\(AB\neq BA\) en général (non commutatif). \((AB)^\top=B^\top A^\top\).

Valeurs/vecteurs propres

\[A v=\lambda v\]

Base de la PCA, PageRank, diagonalisation.

📉 PCA & SVD IA Data📘 Module 2

SVD

\[A = U\Sigma V^\top\]

\(U,V\) orthogonales, \(\Sigma\) diagonale (valeurs singulières).

PCA — marche à suivre

  1. Centrer (et souvent réduire) les données.
  2. Calculer la matrice de covariance \(\;C=\tfrac1n X^\top X\).
  3. Extraire valeurs/vecteurs propres de \(C\).
  4. Garder les \(k\) plus grandes → axes principaux.
  5. Projeter les données sur ces axes.
ButRéduire la dimension en gardant un maximum de variance.

🎲 Probabilités — bases📘 Module 3

RègleFormule
Bornes\(0\le P(A)\le 1\)
Complément\(P(\bar A)=1-P(A)\)
Union\(P(A\cup B)=P(A)+P(B)-P(A\cap B)\)
Conditionnelle\(P(A\mid B)=\dfrac{P(A\cap B)}{P(B)}\)
Indépendance\(P(A\cap B)=P(A)P(B)\)

Probabilités totales

\[P(A)=\sum_i P(A\mid B_i)P(B_i)\]

🔁 Théorème de Bayes IA📘 Module 3

\[P(A\mid B)=\frac{P(B\mid A)\,P(A)}{P(B)}\]
Vocabulaire\(P(A)\) = a priori · \(P(B\mid A)\) = vraisemblance · \(P(A\mid B)\) = a posteriori.
UsageClassification naïve bayésienne, filtres anti-spam, diagnostic.

📐 Statistiques Data📘 Module 4

⛰️ Optimisation IA📘 Module 5

Dérivée & gradient

Minimum/maximum : chercher \(f'(x)=0\). En dimension \(n\) : \(\nabla f=0\).

Descente de gradient

\[\theta \leftarrow \theta - \eta\,\nabla_\theta J(\theta)\]
\(\eta\) = taux d'apprentissageTrop grand → diverge ; trop petit → lent. Variantes : SGD, Adam.

Dérivées utiles

\((x^n)'\)\(n x^{n-1}\)
\((e^x)'\)\(e^x\)
\((\ln x)'\)\(1/x\)
Chaîne\((f\circ g)'=f'(g)\,g'\)

📡 Information IA📘 Module 8

Entropie de Shannon

\[H(X)=-\sum_i p_i\log_2 p_i\quad(\text{bits})\]

Entropie croisée (perte ML)

\[H(p,q)=-\sum_i p_i\log q_i\]

Divergence KL

\[D_{KL}(p\|q)=\sum_i p_i\log\frac{p_i}{q_i}\ge 0\]
UsageCross-entropy = fonction de perte reine de la classification. Gain d'information = construction des arbres de décision.
