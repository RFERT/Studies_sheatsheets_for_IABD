⌨️ Entrées / sorties (I/O)📘 Module 4

Lire une ligne au clavier (stdin)

use std::io::{self, Write};

let mut ligne = String::new();
io::stdin().read_line(&mut ligne).unwrap();
let ligne = ligne.trim();        // enlève le \n final

Lire un nombre

let n: i32 = ligne.trim().parse().expect("pas un nombre");

Lire plusieurs valeurs sur une ligne

let nums: Vec<i32> = ligne.split_whitespace()
    .map(|x| x.parse().unwrap())
    .collect();

Écrire (sortie)

println!("avec saut de ligne");
print!("sans saut "); io::stdout().flush().unwrap(); // force l'affichage
eprintln!("erreur sur stderr");
Piègesread_line garde le \n → toujours .trim(). read_line renvoie un Result (nb d'octets lus). Pour print! sans \n, pense à flush().
Arguments CLI & variables d'env.std::env::args() (itérateur d'arguments) · std::env::var("CLE") (variable d'environnement → Result).

🏗️ Structs & méthodes📘 Module 7

🧬 Génériques & lifetimes📘 Module 12

fn max<T: PartialOrd>(a: T, b: T) -> T {
    if a > b { a } else { b }
}
// lifetime : la sortie vit aussi longtemps que les entrées
fn plus_long<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
★ LifetimesDes étiquettes ('a) qui garantissent qu'une référence ne survit jamais à la donnée pointée. Vérifié à la compilation, zéro coût à l'exécution.

⚠️ Pièges fréquents

  • Le ; final transforme une valeur de retour en ().
  • Move : réutiliser une String/Vec après let b=a; → erreur.
  • & vs &mut : pas de mutable tant qu'un immuable vit.
  • match non exhaustif : ajoute _.
  • Oubli de mut : « cannot assign twice ».
  • unwrap() sur None/Err → panique.
  • Référence pendante : renvoyer & vers une variable locale.
